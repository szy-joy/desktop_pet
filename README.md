# Desktop Pet (巨星监工) - 桌面宠物 & 效率助手

一个基于 Web 的桌面宠物应用，集成了互动娱乐、音乐播放和番茄钟监工功能。你可以自定义宠物的素材、皮肤、互动台词和行为。

## 🚀 核心功能

- **动态交互**：点击宠物随机触发文案，支持多种互动行为（吃饭、发呆、睡觉、运动等）。
- **巨星监工 (番茄钟)**：设定专注时间，宠物会在屏幕上方“监考”你，并显示气泡文案。
- **自定义素材**：支持上传本地图片、GIF、视频和音频作为宠物的动作或背景音乐。
- **外观定制**：自由调节宠物大小、透明度。
- **台词库管理**：自定义宠物的闲聊台词和动作反馈文案。

## 🛠️ 技术栈

- **前端**: React 18, TypeScript, Vite, Tailwind CSS, Framer Motion (动画)
- **后端**: Node.ts (Express)
- **图标**: Lucide React

## 📦 环境要求与依赖安装

确保你的环境中已安装 [Node.js](https://nodejs.org/) (推荐 v18+)。

1. **克隆/下载项目后，安装依赖**：
   ```bash
   npm install
   ```

## 🏃 运行指令

### 1. 开发环境运行
启动前端 Vite 开发服务器和后端 Express API：
```bash
npm run dev
```
运行后访问：`http://localhost:3000`

### 2. 生产环境构建
构建前端静态资源并打包后端脚本：
```bash
npm run build
```

### 3. 生产环境启动
在完成 build 后，使用以下命令启动应用：
```bash
npm start
```

## 📁 目录结构说明

- `src/components/`: UI 组件（设置面板、素材管理、宠物主体等）
-  `server.ts`: 后端服务器，处理配置持久化和素材上传逻辑
- `public/assets/`: 默认素材存放目录
- `config.json`: 应用生成的本地配置文件（由于权限原因，通常在运行时自动生成或通过 API 更新）

## ⚠️ 注意事项

- **素材上传**: 目前仅支持上传文件，不支持直接上传文件夹。
- **浏览器限制**: 部分音效播放可能需要你在页面上有一次点击交互后才能触发（浏览器安全策略）。
