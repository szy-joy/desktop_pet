# Desktop Pet (巨星监工)

## 🛠️ 环境准备
- **Node.js**: 请确保安装了 [Node.js](https://nodejs.org/) (推荐 v18 或更高版本)。

## 📥 安装与运行

> **重要提示**：请务必**以管理员权限（Run as Administrator）**打开终端或命令行工具执行以下指令。

1. **安装依赖** (仅需在第一次使用时运行)
   ```bash
   npm install
   ```

2. **启动项目**
   ```bash
   npm.cmd run electron:dev
   ```

## 🌟 核心功能
- **动作互动**：点击宠物触发随机台词，支持多种互动行为（吃饭、睡觉等）。
- **巨星监工**：内置番茄钟，专注时宠物会在时间框下方陪你。
- **外观调节**：支持自由缩放宠物大小并保存配置。
